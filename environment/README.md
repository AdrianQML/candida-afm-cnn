# Environment specification

The YAML installs the relevant observed scientific dependency closure from requirements-pinned.txt. TensorFlow Quantum and unrelated TFQ packages are excluded. See environment-reference.txt for exact observed versions, runtime distinctions, and verification limits. Optional Jupyter tooling is documented in docs/reproduction.md.

requirements-pinned.txt is an exact-version reference for the observed scientific dependency set, not a cryptographically locked environment.
