# Class-file organization restoration

The independent balanced cross-cell set contains 900 experimental curves from a second Candida albicans cell: 300 each of Nanodomain, Intermediate, and Outside, experimentally defined by AtomicJ ROI selection. Later reorganization restored class-file associations after anonymization/random renaming. The original and labelled archives represent the same cohort. The original preserves blind-workflow filenames; the labelled archive preserves restored organization for sample-level evaluation.

See data/labels/README.md for the mapping schema and source.
